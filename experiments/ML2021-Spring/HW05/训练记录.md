# HW05 Transformer NPU 训练记录

## 环境

- 硬件：昇腾 910 32GB NPU
- 系统：openEuler
- 精度：BF16 混合精度
- 框架：PyTorch（torch_npu）

## 训练参数

```bash
python -m hw05_npu.train \
    --data-dir ./DATA/rawdata/ted2020 \
    --max-tokens 65535 \
    --accum-steps 4 \
    --max-src-len 160 \
    --max-tgt-len 160 \
    --max-epoch 30
```

默认参数：embed_dim=256, ffn_dim=1024, encoder_layers=4, decoder_layers=4, nhead=4, dropout=0.1, lr_factor=2.0, lr_warmup=4000, seed=73
