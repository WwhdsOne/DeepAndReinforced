# HW07 BERT 问答训练日志

## 配置

- 模型: `luhua/chinese_pretrain_mrc_macbert_large` (324M)
- 分词器: `BertTokenizerFast` (同模型)
- 总轮数: 3
- batch_size: 4
- 梯度累积: 8（等效 batch=32）
- 每 epoch 优化步数: 842
- 学习率: 5e-5
- 调度器: warmup 200 步 + CosineAnnealing (T_max=2326, eta_min=1e-6)
- fp16: 启用
- max_paragraph_len: 150
- doc_stride: 37 (×0.25)
- 随机偏移: ±75 (max_paragraph_len // 2)
- 数据集: DRCD + ODSQA（训练 26935 / 验证 3524 / 测试 3492）
