# 实验结果分析

## 过拟合观察

两次实验均出现明显的过拟合现象：

- 训练集持续收敛（loss 从 5.22 降至 0.20，acc 升至 94%）
- 昇腾验证集在 **~25 epoch 后 lock 在 49%** 不再提升，val loss 反而持续上涨
- 训练 loss = 0.20 vs 验证 loss = 3.42，差距 **17 倍**
- Kaggle T4 同样过拟合

## 缓解过拟合

使用更强的正则化参数再次训练：

```bash
python train.py --model VGG11 --epochs 50 --weight-decay 0.001 --dropout 0.6 --batch-size 128
```

| Epoch | Train Loss | Train Acc | Val Loss | Val Acc | Time |
| ----- | ------ | -------- | ------------- | ------------ | -------- |
| 47   | 0.5438 | 84.47% | 2.4808    | 52.11%    | 29s *     |

## 与论文对比

参考文献[^1]中 VGG16 在 Tiny ImageNet 上的极限准确率约为 **49.4%**。本次使用 **VGG11**（更浅的网络）配合正则化优化，准确率达到 **52.11%**，超出约 **1.7%**。

## 🏗️ 架构对比

| 维度 | 你的 VGG11 | 论文 VGG-16 |
|------|-----------|-------------|
| 卷积层数 | **8** | **13** |
| 参数量 | ~9.2M | ~14.7M |
| 配置结构 | `64,M,128,M,256,256,M,512,512,M,512,512,M` | `64,64,M,128,128,M,256,256,256,M,512,512,512,M,512,512,512,M` |
| 差异本质 | 每段下采样前只堆 **1 层浅 → 2 层深** | 每段下采样前堆 **2 层（前3段）或 3 层（后2段）** |
