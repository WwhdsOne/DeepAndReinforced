# Tiny ImageNet-200 数据集介绍

## 概述

Tiny ImageNet-200 是 ImageNet 大规模视觉识别挑战赛（ILSVRC）的一个精简版本，专为快速原型验证和教学目的设计。它由斯坦福大学 CS231n 课程团队创建，常用于深度学习课程的期末项目。

## 基本信息

| 属性 | 数值 |
| :--- | :--- |
| **类别数量** | 200 类 |
| **训练集规模** | 100,000 张（每类 500 张）|
| **验证集规模** | 10,000 张（每类 50 张）|
| **测试集规模** | 10,000 张（无标签，用于竞赛提交）|
| **图像尺寸** | 64 × 64 像素（原始 ImageNet 为 256×256）|
| **来源** | ImageNet 1k 数据集的子集 |
| **数据增强**  | 填充后随机裁剪 + 随机水平翻转 |

## 数据特点

### 类别分布
200 个类别均从原始 ImageNet-1k 中选取，涵盖多种日常物体、动物和场景。每个类别有独立的 WordNet ID（如 `n01443537` 对应 "goldfish"）。

### 文件结构
```
tiny-imagenet-200/
├── train/
│   ├── n01443537/           # 类别文件夹（按 WordNet ID）
│   │   ├── images/          # 该类别的 500 张训练图像
│   │   └── n01443537_boxes.txt
│   └── ...
├── val/
│   ├── images/              # 10,000 张验证图像
│   └── val_annotations.txt  # 图像名 → 类别ID + 边界框
└── test/
    └── images/              # 10,000 张无标签测试图像
```

### 挑战性
- **小尺寸**：64×64 的分辨率使得细粒度特征（如纹理、边缘）难以捕捉
- **过拟合风险**：每类仅 500 张训练图像，远少于完整 ImageNet（每类超 1000 张）
- **类别相似性**：存在易混淆的类别对（如 "train" vs "streetcar"，"goldfish" vs "tuna"）

## 适用场景

- ✅ 教学演示和课程项目
- ✅ 快速原型验证（比完整 ImageNet 训练快 10-20 倍）
- ✅ 过拟合缓解技术研究（数据增强、Dropout、正则化）
- ✅ 小图像分类任务
- ✅ 迁移学习实验（预训练 → 微调）

## 局限性

- ❌ 低分辨率限制了细粒度识别的可能性
- ❌ 与真实应用场景（高清图像）存在 domain gap
- ❌ 类别数量较少，无法完整评估模型在大规模分类上的泛化能力

# VGG

**VGG**（Visual Geometry Group）是牛津大学视觉几何组在 2014 年提出的经典卷积神经网络架构，发表于论文 *"Very Deep Convolutional Networks for Large-Scale Image Recognition"*（Simonyan & Zisserman, 2014）。

VGG 在 2014 年 ImageNet 竞赛中定位任务取得第一名、分类任务第二名，其核心贡献在于**证明了网络深度对性能的提升作用**，并确立了**小卷积核堆叠**的设计范式。

## 核心设计原则

### 1. 小卷积核堆叠

VGG 统一使用 **3×3 卷积核**，摒弃了 AlexNet 中的大卷积核（11×11, 5×5）。**两个 3×3 堆叠**（stride=1, pad=1）等效于**一个 5×5**的感受野，**三个 3×3 堆叠**等效于**一个 7×7**，但：

| 特性 | 单个 7×7 | 三个 3×3 堆叠 |
|:---|:--------:|:-----------:|
| 参数量 | $7^2 C^2 = 49 C^2$ | $3 \times 3^2 C^2 = 27 C^2$ |
| 非线性层数 | 1 层 ReLU | 3 层 ReLU |
| 正则化效果 | 无 | 隐含正则化（更深的非线性变换） |

> 参数量减少约 **45%**，且更多的非线性层提升了判别能力。

### 2. 深度的系统探索

论文系统性地比较了从 11 层到 19 层的不同深度配置，证明了**增加深度可以提升性能**，这一发现在当时极具影响力。

### 3. 结构简洁统一

- 所有卷积层：`3×3` 核，`pad=1`，`stride=1`
- 所有池化层：`2×2` 窗口，`stride=2`
- 所有全连接层后接 ReLU + Dropout（可通过 `--dropout` 调整）

每个池化层后特征图尺寸减半、通道数加倍（从 64 递增到 512）。

### 4. 优化器

- 带动量的 SGD（SGD+Momentum），泛化性能在当前场景下会相对于Adam会好一些
- 默认 **momentum=0.9**
- 默认 **weight_decay=5e-4**,weight_decay就是 L2 正则化
