# 学习日志目录结构

本目录存放学习日志，分为两个子目录：

## 目录说明

### daily/

存放每日学习日志，文件名格式：`YYYY-MM-DD.md`

例如：
- `2026-05-21.md` — 2026年5月21日的学习记录

### report/

存放阶段性总结报告，文件名格式：`YYYY-MM-DD_主题.md`

例如：
- `2026-05-20_鱼书前六章总结.md` — 鱼书前六章学习总结

## 日志内容建议

每日日志可包含：
- 主题
- 今日完成的工作
- 关键代码路径
- 遇到的问题和解决方案
- 技术要点总结
- 下一步计划

阶段性报告可包含：
- 一段时间内的学习进展
- 知识体系梳理
- 心得体会
- 后续学习计划
