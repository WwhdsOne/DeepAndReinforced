### 1. 实现卷积层（Convolution）

**文件**: `experiments/fish-book/common/ConvolutionLeayer.py`

- 实现 `Convolution` 类，支持卷积前向/反向传播
- **前向传播**：
  - 使用 `im2col` 将输入图像展开为矩阵（避免多重循环，利用 NumPy 矩阵运算加速）
  - 权重 `W` 展平为 `(C*FH*FW, FN)` 形状
  - 矩阵乘法计算输出：`out = col @ col_W + b`
  - 输出形状调整：`(N, out_h, out_w, FN)` → `(N, FN, out_h, out_w)`
- **反向传播**：
  - `db`：对 `dout` 按输出通道求和
  - `dW`：通过 `col.T @ dout` 计算，再还原为权重形状
  - `dx`：通过 `dout @ col_W.T` 计算 `dcol`，再用 `col2im` 还原为输入形状
- 保存中间变量 `self.x`、`self.col`、`self.col_W` 用于反向传播

### 2. 实现池化层（Pooling）

**文件**: `experiments/fish-book/common/PoolingLayer.py`

- 实现 `Pooling` 类，支持最大池化前向/反向传播
- **前向传播**：
  - 使用 `im2col` 展开输入
  - 使用 `np.max` 计算每个池化窗口的最大值
  - **关键**：保存 `arg_max`（最大值位置），用于反向传播时梯度回传
- **反向传播**：
  - 构建全零矩阵 `dcol`
  - 根据 `arg_max` 将梯度放到最大值位置（`np.arange(dout.size), self.arg_max = dout`）
  - 使用 `col2im` 还原为输入形状

### 3. 构建简单卷积网络（SimpleConvNet）

**文件**: `experiments/fish-book/ch7/SimpleConvNet.py`

- 网络结构：
  ```
  Input → Conv1 → ReLU → Pool1 → Affine1 → ReLU2 → Affine2 → SoftmaxWithLoss
  ```
- 初始化参数：
  - `W1`：卷积核，形状 `(FN, C, FH, FW)`，Xavier 初始化
  - `W2`：全连接层1权重，形状 `(pool_output_size, hidden_size)`
  - `W3`：全连接层2权重，形状 `(hidden_size, output_size)`
- 实现方法：
  - `predict(x)`：前向传播
  - `loss(x, t)`：计算交叉熵损失
  - `accuracy(x, t, batch_size)`：分批计算准确率（避免内存爆炸）
  - `gradient(x, t)`：反向传播，返回梯度字典

## 技术要点

### im2col/col2im 技巧

- **im2col**：将卷积操作转换为矩阵乘法，避免多重循环
  - 输入 `(N, C, H, W)` → 展开为 `(N*out_h*out_w, C*FH*FW)`
  - 卷积核 `(FN, C, FH, FW)` → 展平为 `(C*FH*FW, FN)`
  - 矩阵乘法：`(N*out_h*out_w, C*FH*FW) @ (C*FH*FW, FN)` → `(N*out_h*out_w, FN)`
- **col2im**：反向传播时将梯度还原为输入形状

### 卷积输出尺寸计算

```
out_h = (H + 2*pad - FH) / stride + 1
out_w = (W + 2*pad - FW) / stride + 1
```

### 池化层反向传播技巧

- 最大池化：梯度只传给前向传播时最大值的位置
- 使用 `arg_max` 记录最大值索引，反向传播时将梯度放到对应位置
