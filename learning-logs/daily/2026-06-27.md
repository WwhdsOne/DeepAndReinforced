### HW07 作业完成与优化

在原始 baseline 基础上做了以下改动：

| 优化项 | 原始值 | 当前值 | 原因 |
|---|---|---|---|
| fp16 混合精度 | 关闭 | **开启** | T4 支持，训练提速约 2 倍 |
| 预训练模型 | bert-base-chinese | **chinese-roberta-wwm-ext** | WWM + 更多数据，中文 QA 更强 |
| max_paragraph_len | 150 | **128** | 缩短序列，单步前向更快 |
| doc_stride | 150（无重叠） | **64**（50% 重叠） | 防止答案在窗口边界被截断 |
| 学习率调度 | 无 | **warmup 500 步 + 余弦退火** | 稳定训练初期，后期充分衰减 |
| T_max | 固定 10000 | **随 num_epoch 自动计算** | 与实际训练步数对齐 |
| 预处理（TODO 1） | 答案始终居中 | **随机偏移 ±32** | 防止模型学"答案在中间"捷径 |
| 后处理（TODO 2） | logit 相加 | **softmax 后概率相乘** | 修正联合概率计算方式 |
| 模型保存 | 保存最后一轮 | **early stopping 保存最优** | 防止过拟合覆盖好模型 |

### 关键概念理解

- **logit vs 概率**：模型最后一层输出是未经 softmax 的原始分数，直接相加无意义，需先转概率再比较
- **doc_stride 与 max_paragraph_len 的关系**：stride 必须小于窗口长度才能保证重叠，否则长段落会有"盲区"
- **batch_size 与迭代次数的权衡**：固定 epoch 数下，加大 batch 会减少梯度更新次数，1 epoch 时尤其不利

## 今日收获

- **BERT 微调 QA 的核心流程**：分词 → 滑窗截断 → 模型预测 start/end 位置 → 后处理选最优答案
- **过拟合信号识别**：epoch 1 验证 67%，epoch 3 降到 55%，典型的过拟合。early stopping 是必备手段
- **max_paragraph_len 的直观理解**：每个窗口能装多少段落 token，窗口之间靠 doc_stride 滑动覆盖全文
- **参考真实排行数据**：原始 baseline 在 Kaggle 上只有 ~0.485，随机窗口偏移一项就能拉到 ~0.764，收益巨大
