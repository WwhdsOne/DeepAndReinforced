### lecture-10: 卷积神经网络 MNIST 分类

**文件**: `experiments/liuerdaren/lecture-10.py`

- 使用 PyTorch 实现三层卷积网络进行 MNIST 分类
- 模型结构：
  - `Conv2d(1,16,3,padding=1)` → `ReLU` → `MaxPool2d(2,2)` (28→14)
  - `Conv2d(16,32,3,padding=1)` → `ReLU` → `MaxPool2d(2,2)` (14→7)

- 优化器：`Adam(lr=0.01)`

## 学习笔记

1. **全连接 vs 卷积**：
   - 全连接网络：参数量大，容易过拟合，适合小规模数据
   - 卷积网络：参数共享，局部连接，适合图像数据

2. **卷积层尺寸计算**：
   - 输出尺寸 = (输入尺寸 - 卷积核大小 + 2×填充) / 步长 + 1
   - 池化层尺寸 = (输入尺寸 - 池化核大小) / 步长 + 1

3. **padding 的作用**：
   - 保持空间尺寸不变
   - 对于奇数卷积核，padding = kernel_size // 2

4. **优化器选择**：
   - SGD + Momentum：泛化性能好，但收敛慢
   - Adam：收敛快，但可能过拟合
