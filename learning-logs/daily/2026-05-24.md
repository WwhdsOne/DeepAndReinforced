# 2026-05-24 学习日志

## 今日完成

- 在 **Kaggle（T4×2）** 和 **昇腾 910B3** 两个平台上完成 VGG11 在 Tiny ImageNet-200 上的完整训练测试
- 最佳结果：**52.11%**（昇腾 910B3，Epoch 47）

## 关键超参数


| 参数名称 | 参数值 |
| :--- | :--- |
| `--model` | VGG11 |
| `--epochs` | 50 |
| `--weight-decay` | 0.001 |
| `--dropout` | 0.6 |

增大 weight decay 和 dropout 后验证准确率从 ~49% 提升至 52.11%，有效缓解了过拟合。

## 超越论文

参考论文：*Tiny ImageNet Challenge*, Anna Shcherbina, CS231n Course Project Report, Stanford University, 2016.
该论文中 VGG16 在 Tiny ImageNet 上极限准确率约 **49.4%**。
本次 VGG11 达到 **52.11%**，超出约 **1.7%**。
