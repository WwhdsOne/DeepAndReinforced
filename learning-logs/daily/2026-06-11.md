# 2026-06-11 学习日志

正式开始学习《动手学强化学习》，第一章：多臂老虎机（Multi-armed Bandit）。

## 今天做了什么

在 `experiments/hands-on-rl/bernoulli-bandit/` 实现了伯努利多臂老虎机的基础实验框架：

- **环境**：`BernoulliBandit`，K 根拉杆各自拥有随机获奖概率，每次拉动返回 0/1 奖励
- **基类**：`Solver`，负责维护拉杆计数、累积懊悔（cumulative regret）与动作历史
- **两种策略对比**：
  - `EpsilonGreedy`：以 `epsilon=0.01` 概率随机探索，否则贪心选择经验均值最大的拉杆
  - `DecayingEpsilonGreedy`：探索率按 `epsilon / t` 衰减，随时间逐步收敛到纯贪心

跑了 5000 步对比实验（10 臂，获奖最大拉杆 5 号、概率 0.7999）：

| 策略 | 累积懊悔 |
|---|---|
| EpsilonGreedy (eps=0.01) | 19.88 |
| DecayingEpsilonGreedy (eps=0.01/t) | 3.49 |

固定 epsilon 的策略每一步都保留随机探索，懊悔持续线性增长；而衰减版本后期几乎只拉最优杆，懊悔曲线明显更平缓。

## 踩的坑

调试过程中遇到两个 PyTorch 与 Python 混用的小坑，记录一下：

1. **`self.regrets` 被同时当标量和列表使用**：原代码先赋 `self.regrets = 0.` 再 `self.regrets = []`，`update_regret` 里 `+=` 与 `append` 互相覆盖。拆分为 `self.regret`（标量）+ `self.regrets`（历史列表）即可。
2. **Tensor 原地累加导致列表全是同一个引用**：`self.regret += tensor` 走的是 tensor 的 `__radd__` 原地修改，`self.regret` 始终是同一个对象，`append` 5000 次都指向它，画图时所有点读的是最终值，看起来就是一条水平直线。修复方式：追加前 `.item()` 取出 Python float。

## 收获

- 理解了多臂老虎机问题"探索 vs. 利用"的核心矛盾
- 累积懊悔（cumulative regret）是评价 bandit 策略最常用的指标，理论下界为 `O(log T)`
- epsilon-greedy 的累积懊悔是 `O(T)`（线性），而 UCB、Thompson Sampling 等可以逼近 `O(log T)`
