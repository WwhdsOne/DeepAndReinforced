## 环境设计 (`aim_trainer_env.py`)

### 核心机制
- 状态：准星 `[x, y]` + 最近目标相对位置（归一化）
- 动作：`[dx, dy]` 连续位移，步长自适应靶子半径
- 命中：准星进入目标半径内自动计分，目标重生

### 调参参数（已参数化）
| 参数 | 默认值 | 作用 |
|---|---|---|
| `target_radius` | 0.04 | 靶子半径 |
| `action_step` | auto (r×0.4) | 最大位移步长，自动防止一步跳过靶子 |
| `hit_reward` | 10.0 | 命中基础奖励 |
| `time_penalty` | 0.01 | 每步时间惩罚基准 |
| `time_ramp` | 5.0 | 时间惩罚阶梯递增倍数 |
| `efficiency_coef` | 2.0 | 路径效率系数，命中越快越高 |
| `progress_coef` | 0.2 | 靠近奖励/新纪录奖励系数 |
| `near_zone_scale` | 3.0 | 引导圈半径倍数 |
| `near_zone_min` | 0.06 | 引导圈半径下限 |
| `distance_delta_coef` | 0.6 | 每步距离变化奖励系数 |
| `regress_penalty_scale` | 1.5 | 远离目标额外惩罚倍数 |
| `idle_threshold` | auto | 发呆判定阈值 |

## 奖励函数演化（今日多次迭代的核心问题）

### 问题：agent 在目标边缘转圈蹭分，不命中
**根因**：原始"绝对靠近奖励"（越近越给分）制造了局部最优——agent 贴边转圈稳定拿 0.04/步，比冒险命中更划算。

### 迭代历程

1. **绝对靠近奖励 → 进步奖励**
   - 改成 `progress_coef * (prev_nearest - cur_nearest)`，只有缩短距离才给分
   - **问题**："最近目标"会在多目标间切换，agent 通过切换目标作弊

2. **进步奖励 → 绝对靠近奖励（缩小范围）**
   - 只在内圈（near_zone = 2.5×半径）给分
   - **问题**：引导圈范围缩小到 1.2×半径后区间过窄，agent 每步纯亏，无法发现命中

3. **砍掉靠近奖励**
   - 只保留命中 + 时间惩罚
   - **问题**：旧策略惯性未消，agent 仍然绕圈；没有梯度引导，命中靠碰巧

4. **一次性靠近奖励（当前方案）**
   - 每个目标首次进入引导圈给一次分，二次蹭不给
   - 命中后重置资格
   - 扩大引导圈（3×半径，最小 0.06）

5. **距离变化奖励**
   - 每步按距离变化给分：靠近正奖励，远离惩罚（1.5x）

6. **新纪录奖励**
   - 对当前 episode 内的最优距离进行新纪录奖励，避免只在最终命中时给信号

7. **其他惩罚项**
   - 发呆惩罚：动作幅度低于阈值额外扣 time_penalty×5
   - 时间惩罚递增：从 1x 线性增到 time_ramp×（默认 5x）

8. **步长自适应**
   - 动作步长自动 = max(target_radius × 0.4, 0.004)
   - 解决 target_radius=0.02 时一步跳过靶子的问题

## 观察与经验

1. **奖励整形陷阱**：任何"越近越给分"的奖励都会制造局部最优，agent 会选择稳定的蹭分而非冒险命中

2. **步长与靶子匹配**：步长必须小于靶子直径，否则 agent 一步就能跨过靶子永远撞不上

3. **梯度引导必要性**：完全去掉中间奖励会导致稀疏奖励问题——早期探索阶段命中概率太低，缺乏引导信号

4. **一次性引导 + 持续距离变化奖**是目前观察到的较好平衡
