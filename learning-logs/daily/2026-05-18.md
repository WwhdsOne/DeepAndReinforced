## 主题：Ch6 神经网络优化实战 — BatchNorm、Adam、L2 正则化

## 今日完成

### 1. 新增 BatchNormalizationLayer

**文件**: `experiments/fish-book/common/batchNormalizationLayer.py`

- 实现 `BatchNormalizationLayer` 类，接口风格与现有 Layer 一致（`forward` / `backward`）
- 前向传播：计算 mini-batch 均值/方差 → 标准化 → 缩放平移（γ、β），训练时更新移动平均
- 反向传播：沿计算图 `out → x̂ → xc → x` 逐步回溯，同时计算 `dγ`、`dβ`
- 通过 `train_flg` 参数区分训练/推理模式
- 在 `common/layers.py` 中导出，并添加别名 `BatchNorm`

### 2. MultiLayerNet 接入 BatchNorm

**文件**: `experiments/fish-book/ch6/train_nn.py`

网络结构改为：

```
Affine1 → BatchNorm1 → Relu1 → Affine2 → BatchNorm2 → SoftmaxWithLoss
```

主要改动：

- `params` 新增 `gamma1`、`beta1`、`gamma2`、`beta2`
- `predict` 方法增加 `train_flg` 参数，BatchNorm 层透传该标志
- `loss` 调用 `predict(x, train_flg=True)`
- `gradient` 返回所有 8 个参数的梯度

### 3. 新增 Adam 优化器

**文件**: `experiments/fish-book/common/optimizer.py`

- 实现 `Adam` 类：`__init__(lr, beta1, beta2, eps)` + `update(params, grads)`
- 偏差修正实现完整，一阶/二阶矩估计正确
- 在 `common/layers.py` 中导出
- `train_nn.py` 训练循环中用 `optimizer.update(network.params, grad)` 替换手动 SGD 更新

### 4. Dropout 推理模式 bug 修复

**文件**: `experiments/fish-book/ch6/train_nn.py`

- **问题**：`predict` 方法没有把 `train_flg` 传给 Dropout 层，导致推理时 Dropout 仍在随机丢弃神经元
- **修复**：在 `predict` 的循环中增加 `isinstance(layer, Dropout)` 分支，透传 `train_flg`

### 5. L2 正则化（Weight Decay）

**文件**: `experiments/fish-book/ch6/train_nn.py`

- 在 `TwoLayerNet.loss` 方法中加入 L2 惩罚项：`ce_loss + lambda_reg * (W1² + W2²)`
- 默认 `lambda_reg=1e-4`，只对权重参数 W 施加惩罚，bias、gamma、beta 不参与

## 调试记录

### Dropout 推理时仍在丢弃

- **现象**：加了 Dropout 后准确率反而下降
- **根因**：`predict` 方法的 `for` 循环只处理了 `BatchNorm` 的 `train_flg`，Dropout 收到的是默认 `train_flg=True`
- **修复**：增加 `elif isinstance(layer, Dropout)` 分支
