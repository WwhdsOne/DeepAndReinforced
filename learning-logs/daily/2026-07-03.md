# 2026-07-03 学习日志

HW08 异常检测作业全流程优化，从原始 baseline 一路迭代到论文级方案，Kaggle Private Score 达到 0.80371。

## 今天做了什么

### 第一阶段：基础优化（Medium → Strong）

| 改动 | 说明 |
|---|---|
| 更小 CNN | 移除 96ch 层，减少参数量 |
| BatchNorm | 所有 Conv 层后加 BN，稳定训练 |
| batch_size 10000→256 | 更小批次，梯度更稳定 |
| epochs 50→500 | 充分训练 |
| AdamW 替换 Adam | 解耦 weight decay |

### 第二阶段：Boss baseline 架构

| 改动 | 说明 |
|---|---|
| 宽 FCN | 12288→4096→2048→1024→256→128，BatchNorm + PReLU |
| Warmup + Cosine Annealing | 1000 步 warmup，余弦衰减学习率 |
| CenterCrop(56) → Resize(64) | 面部 ROI 放大 14% |
| fp16 混合精度 | GradScaler，T4 提速 2x |

### 第三阶段：评分策略迭代

**分类器方案（失败）：**
- 噪声感知分类器（正常 vs 合成噪声），组合评分 = recon + α × cls_score
- 问题：分类器 3 epoch 就 loss 归零，合成噪声与真实异常差距太大
- 尝试了高斯噪声、部分损坏、通道打乱等"难负样本"，仍然快速收敛
- **结论：分类器路线走不通**

**Mahalanobis + Feature Distance 方案（成功）：**
- 提取 encoder 128 维 latent 特征，拟合高斯分布（均值 + 协方差）
- Mahalanobis 距离：衡量测试样本偏离正常分布的"统计距离"
- Feature Distance：latent 空间到最近训练样本的欧氏距离
- 组合公式：`score = normalize(recon) + 0.3×normalize(maha) + 0.1×normalize(feat)`

### 第四阶段：论文级优化（最终方案）

| 改动 | 说明 |
|---|---|
| CNN 架构重写 | 32→64→128→256, AdaptiveAvgPool→128d bottleneck，与 FCN latent 维度一致 |
| 去掉 CenterCrop | 64×64 已经很小，裁剪会丢边缘异常 |
| 多尺度重构损失 | CNN decoder 在 16×16、32×32 输出中间重建，监督下采样原图 |
| SSIM Loss + L1 | CNN 用 0.5×L1 + SSIM，FCN 保持 MSE |
| Mahalanobis 权重 0.3 | 原来 0.01 基本无效 |
| Feature Distance | latent 最近邻距离作为第三评分维度 |
| CNN lr=3e-4 | CNN 比 FCN 更需要保守的学习率 |
| 双模型 Ensemble | FCN + CNN 融合，各自捕捉不同层面异常 |

## 踩坑记录

**1. 分类器 loss 归零**
纯随机噪声太容易区分，分类器学不到有用信息。换成更难负样本后仍然 3 epoch 归零。本质问题：分类器学到的是"区分真实图和人工噪声"而非"区分正常和异常"。

**2. 升腾 NPU fp8 不支持**
Ascend 910B3 的 autocast 不支持 float8_e4m3fn，只支持 fp16/bf16/fp32。加了探测逻辑自动回退到 bf16。

**3. 计算图冲突**
AE 和分类器共享计算图时，AE backward 释放图后分类器 backward 报错。解法：两者独立训练，不共享梯度。

**4. torch.load weights_only 问题**
PyTorch 2.6+ 默认 weights_only=True，保存完整模型对象需要设为 False。

## 今日收获

- **像素级 MSE 是异常检测的基础，但不是终点**：Mahalanobis 距离在 latent 空间提供了更鲁棒的异常信号
- **分类器不一定有效**：当负样本与真实异常分布差距大时，分类器只是过拟合合成噪声
- **CNN 和 FCN 真正互补**：FCN 擅长全局像素异常，CNN 擅长局部纹理/结构异常
- **bottleneck 维度一致是 Ensemble 的前提**：两个模型 latent 都是 128 维，Mahalanobis 才有意义
- **多尺度监督借鉴 RAEv2**：中间层也做重建，让 encoder 各层都学到有意义的特征
- **SSIM 比 MSE 更关注结构**：对光照变化不敏感，对纹理/边缘变化更敏感
