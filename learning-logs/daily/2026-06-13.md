### HW02-2：Hessian Matrix 作业

学习 Hessian 矩阵的概念及其在神经网络优化中的应用。

- **Hessian 矩阵**：损失函数对参数的二阶导数矩阵，描述优化地形
- **判断规则**：
  - 梯度范数 < 1e-3 → 临界点
  - 正特征值比例 > 0.5 → local minima like
  - 正特征值比例 ≤ 0.5 → saddle point
- **代码实现**（TA 提供，理解概念即可）：
  - 前向传播时 hook 保存每层激活值 A
  - 反向传播时获取反向传播值 B
  - 用 Gauss-Newton 近似：`H ∝ (B×A) ⊗ (B×A)` 对 batch 求和
  - 对展平的 Hessian 做特征值分解，计算最小比率
- 示例输出：gradient norm = 0.072，远大于 1e-3，答案为 none of the above（未收敛到临界点）
- 代码路径：`experiments/ML2021-Spring/HW02/HW02-2.ipynb`
