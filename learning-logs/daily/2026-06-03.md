## 核心知识点

### 1. 观测空间增强：nearest_target_dx/dy

观测从 `2 + n*3` 维扩展为 `2 + n*3 + 2` 维，末尾新增最近目标的相对向量。之前的观测只是平铺所有目标坐标，agent 没有直接的方向信息，容易开局固定方向偏移。加上后训练稳定性明显提升。

### 3. eel 库：Python 模型 ↔ 浏览器渲染

`ai_play.py` 用 `eel` 实现 Python ↔ JavaScript 双向通信：

```python
@eel.expose
def step(dt):
    obs = env.get_obs()        # 从环境拿观测
    action, _ = model.predict(obs, deterministic=True)  # PPO 推理
    env.step(action)           # 执行动作
    return env.get_state()     # 推送状态到浏览器
```

- Python 端加载已训练的 PPO 模型做推理
- 浏览器 HTML 游戏负责渲染，通过 `eel.expose` 暴露 JS 函数供 Python 调用
- 相比纯浏览器端推理（ONNX/TF.js），直接用 SB3 模型更简单、无需导出
