# 2026-06-21 学习日志

今天完成了 HW05 从 RNN 到 Transformer 的架构升级，并构建了独立的多设备训练脚本，部署到升腾 910 NPU 服务器进行训练。

## 今天做了什么

### Transformer 架构升级

将 HW05 的 seq2seq 模型从 RNN (GRU) 升级为 Transformer，核心新增：

- **PositionalEncoding**：正弦位置编码，为 Transformer 提供序列位置信息
- **TransformerEncoder**：使用 `nn.TransformerEncoderLayer` × 4 层（d_model=256, nhead=4, ffn=1024）
- **TransformerDecoder**：使用 `nn.TransformerDecoderLayer` × 4 层 + causal mask
- 更新了 `build_model` 和 `arch_args` 适配 Transformer 参数

### 跨设备兼容性修复

升级过程中发现并修复了多个设备兼容问题：

| 问题 | 原因 | 修复 |
|------|------|------|
| beam search 崩溃 | Transformer 是 batch-first，扩展维度用了 dim=1（seq-first 的 batch 维度） | 检测 encoder 类型，batch-first 用 dim=0 |
| 共享权重被覆盖 | `init_params` 对 Embedding 和 Linear 各初始化一次同一个 tensor | 初始化后重新绑定共享权重 |
| MPS 嵌套张量报错 | `nn.TransformerEncoder` fast path 不支持 MPS | `enable_nested_tensor=False` |
| NPU fused op fallback | `_transformer_encoder_layer_fwd` 不支持 NPU | 手动循环调用 EncoderLayer，不走 fused path |
| `NoneType.dim()` | Transformer encoder 返回 None 作为 hidden states | beam search 加 None 检查 |

### 独立训练脚本 `train_npu.py`

从 notebook 中提取出完整的独立训练脚本，支持四种设备：

- **CUDA**：FP16 混合精度 + GradScaler
- **NPU（升腾 910）**：BF16 混合精度（无需 GradScaler，比 FP16 更稳定）
- **MPS**：FP32，自动调大 batch size
- **CPU**：FP32，保守 batch size

脚本特性：
- 自动下载和预处理数据集（已有则跳过）
- 环境自动检测，动态调整 num_workers / max_tokens / accum_steps
- 可配置 BLEU 验证频率（`validate_every`）
- 日志同时输出到终端和文件（`train_{device}.log`）
- 支持命令行参数配置

### 训练参数优化

| 参数 | 说明 |
|------|------|
| `max_train_samples` | 限制训练数据量用于快速调试 |
| `max_valid_samples` | 限制验证集大小 |
| `validate_every` | 每 N 个 epoch 跑一次完整 BLEU（其余只算 loss） |

### Notebook 配置自动化

Config 加入环境自动检测：CUDA / MPS / CPU 各用不同的 num_workers、max_tokens、accum_steps，上传 Colab 无需手动改参数。

## 今日收获

- **Transformer vs RNN 的工程差异**：batch-first vs seq-first 的维度约定差异会导致隐蔽的 shape 错误，需要在 beam search 等下游代码中做适配。
- **升腾 910 支持 BF16**：BF16 指数范围与 FP32 相同，不需要 GradScaler，训练更稳定。T4 (Turing) 只支持 FP16。
- **nn.TransformerEncoder 的 fused path**：在不同设备上可能触发不支持的融合算子，需要手动拆分为逐层循环调用。
- **Docker 容器无法 shutdown**：云服务器通常是 Docker 容器，没有 systemd，无法用 `shutdown` 命令，需要通过平台 API 或网页关机。
