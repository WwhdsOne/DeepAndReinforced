## 技术要点

### PyTorch 版与 NumPy 版的主要区别

| 组件 | NumPy 版 | PyTorch 版 |
|------|----------|------------|
| 网络定义 | 手动管理 `OrderedDict` | `nn.Module` 子类 |
| 层实现 | `common.layers` 手写 | `nn.Linear`、`nn.BatchNorm1d`、`nn.Dropout` |
| 初始化 | 手写 Kaiming/Xavier | `nn.init.kaiming_normal_`、`nn.init.xavier_normal_` |
| 优化器 | 手写 `Adam` | `torch.optim.Adam` |
| 正则化 | 手动添加 L2 损失 | `weight_decay` 参数 |
| 训练/推理切换 | `train_flg` 参数 | `self.train()` / `self.eval()` |

### PyTorch 训练技巧

- **设备选择**：`device = torch.device("cuda" if torch.cuda.is_available() else "cpu")`
- **学习率调度**：使用 `torch.optim.lr_scheduler.StepLR` 实现每个 epoch 衰减
- **One-hot 转换**：`torch.eye(num_classes)[labels]`
- **准确率计算**：`(preds == labels).float().mean().item()`
