## 技术要点

### PyTorch 版与 NumPy 版的对比

| 组件 | NumPy 版 | PyTorch 版 |
|------|----------|------------|
| 卷积层 | 手写 `Convolution` 类（im2col + 矩阵乘法） | `nn.Conv2d` |
| 池化层 | 手写 `Pooling` 类（im2col + max + argmax） | `nn.MaxPool2d` |
| 全连接层 | 手写 `Affine` 类 | `nn.Linear` |
| 激活函数 | 手写 `Relu` 类 | `F.relu` |
| 损失函数 | 手写 `SoftmaxWithLoss` 类 | `F.cross_entropy` |
| 前向传播 | 手动调用各层 `forward` 方法 | `forward` 方法 + `F` 函数 |
| 反向传播 | 手动实现各层 `backward` 方法 | 自动求导（`autograd`） |
| 权重初始化 | 手写 Xavier 初始化 | `nn.init.xavier_normal_` |
| 优化器 | 手写 `SGD` 或 `Adam` | `torch.optim.Adam` |
| 训练循环 | 手动更新参数 | `optimizer.zero_grad()` + `loss.backward()` + `optimizer.step()` |

### PyTorch 训练技巧

- **设备选择**：`device = torch.device("cuda" if torch.cuda.is_available() else "cpu")`
- **分批计算准确率**：避免全量数据一次性前向传播导致内存爆炸
- **One-hot 转换**：`torch.eye(num_classes)[labels]`
- **准确率计算**：`(preds == labels).float().mean().item()`
