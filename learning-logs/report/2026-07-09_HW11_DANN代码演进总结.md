## 阶段 2：增强 v1（07-08）

三处增强落地，预期合计 +2~3%：

### 2.1 LR 不衰减到 0（预期 +0.5%）

`create_lr_scheduler` 增加 `min_lr_ratio`（初版 0.05，后降至 0.01）：

```python
# cosine 在 [min_lr_ratio, 1.0] 之间插值
min_lr = min_lr_ratio * base_lr
lr = min_lr + 0.5 * (base_lr - min_lr) * (1 + cos(π * progress))
```

末段学习率不再归零，收尾阶段仍能继续学习。

### 2.4 伪标签诊断打印

输出高置信伪标签总数、各类数量、置信度分桶、均衡后数量，便于判断伪标签质量。

## 阶段 3：伪标签 0/100000 Bug 修复（07-08）

### 现象

用户 NPU 上跑伪标签：`0/100000 样本通过阈值 0.95`，无任何高置信伪标签。

### 根因分析

**源/目标域输入变换不一致**：

- `source_transform`：照片 → **Canny 边缘图** → 喂给网络
- `target_transform` / `test_transform`：手绘 → **原始灰度图**（无 Canny）

特征提取器学到的是「边缘图」特征，推理时喂「原始灰度手绘」→ 输入空间差太远 → softmax 接近均匀 → 10 万张里一张 0.95 都碰不出。

> ⚠️ 此 bug 同时坑了最终推理（submission 近随机），只是 DANN 训练时无法测目标域精度，一直没暴露。

### 修复

给 `target_transform`、`test_transform` 加 Canny，使源/目标输入空间一致。修改后旧 `.bin` 不兼容，必须重新训练。

### 增强：自适应阈值

新增「目标域置信度分布」直方图（七档）+ 自适应放宽阈值（高置信不足 500 时自动下调到 floor=0.7）。

> **注意**：后续参考强基线时发现 target 不该做 Canny（手绘已是天然边缘图），此修复方向在阶段 5 被修正。

## 阶段 4：Entropy Minimization 加回（07-09）

用户要求本次加回 Entropy Minimization：

```python
# train_epoch Step 2：对目标域预测算熵
prob_t = torch.softmax(label_predictor(feature[n_source:]), dim=1)
loss_ent = -(prob_t * torch.log(prob_t + 1e-8)).sum(1).mean()
loss_F = loss_F + ent_weight * lamb * loss_ent  # 复用 adaptive_lambda 做 ramp-up
```

- `--ent` 默认开、`--no-ent` 关、`--ent-weight` 可调（默认 0.1）
- 权重乘 `adaptive_lambda`：训练早期几乎不生效，后期渐强

同时 `min_lr_ratio` 从 0.05 降至 0.01（末段地板更温柔），打印标签从 `min_lr=0.05` 改为 `min_lr_ratio=0.01 (末段 lr≈1.0e-05)` 避免误读。

## 阶段 5：参考 NTU 强基线重写（07-09）

用户提供参考作业 `hw11_domain_adaptation.ipynb`（Arvin Liu 强基线），要求"学习他的方法，他没用到的就删除"。

### 对照分析

| 技巧 | 参考做法 | 我们原版 | 采纳？ |
|:-----|:---------|:---------|:------|
| loss_balance | 训练时强制 `softmax(cls*10).mean ≈ uniform`，`*3` | ❌ 只推理端均衡 | ✅ 强烈推荐 |
| Decoder AE | 特征重建输入图 + denoising，`*3` | ❌ | ✅ 采纳 |
| 随机 Canny | source 参数随机 `[170,200)×[250,300)` | 固定 `(170,300)` | ✅ 采纳 |
| RandomErasing | 两次 `p=0.25` | ❌ | ✅ 采纳 |
| target 不 Canny | 只 Grayscale+Resize | 我们之前加了 Canny | ✅ 修正 |
| margin 伪标签 | `top2/top1 < 0.5 & top1 ≥ 0.3` | 绝对阈值 0.95 | ✅ 采纳 |
| 训练时长 | 500 epoch（200 不稳） | 200 epoch | ✅ 采纳 |
| TTA | 未用 | 有 | ❌ 删除 |
| Entropy | 未用（用 balance 替代） | 有 | ❌ 删除 |
| min_lr_ratio | cosine 直接到 ~0 | 有 | ❌ 删除 |

### 重写内容

**采纳（新增）：**
- **loss_balance**：`balance_criterion = nn.MSELoss()`，`NF.softmax(class_logits * 10, 1).mean(0)` vs `uniform_dist`，权重 `*3`
- **Decoder 自编码器**：`ConvTranspose2d` 五层反卷积，512 维特征 → 32×32 单通道图；denoising（`uniform_noise p=0.02`）；`ae_criterion = nn.MSELoss()`，权重 `*3`
- **source 随机 Canny**：`np.random.randint(170,200)` / `np.random.randint(250,300)`
- **×2 RandomErasing**：`p=0.25, scale=(0.03,0.07)`，一黑一白
- **target/test 去 Canny**：只 Grayscale + Resize（手绘已是天然边缘图）
- **margin 伪标签**：`top2[:,1]/top2[:,0] < 0.5 & top2[:,0] >= 0.3` + 类反比加权 `weight = mean/count`
- **LR cosine 到 `eta_min=1e-6`**（≈0），默认 500 epoch
- 保留 ResNet18 backbone（输出 512 维，兼容 Decoder）

**删除（参考未用）：**
- ❌ TTA（`apply_tta` / `use_tta` / `tta_times`）
- ❌ Entropy Minimization（`loss_ent` / `running_ent` / `ent_weight`）
- ❌ min_lr_ratio（LR 不归零）
- ❌ target/test 的 Canny

**新增模型/保存：** `Decoder` 类 + `ae_model.bin` 保存 + `SubsetCustomLabel` 伪标签数据集包装。

### Backbone 决策

参考作业用 5 层 conv，我们用 ResNet18（已验证 0.73274）。因两者均输出 512 维特征，ResNet18 可直接接参考的 Decoder/AE，保留已验证优势，风险最低。

## 阶段 6：半监督训练改进（07-09）

### 问题

用户服务器实测 **45/500 epoch 即达 0.85 acc**，触发半监督启动条件后，剩下 455 个 epoch 全是纯伪标签自训练（`train_cls_epoch` 只吃 target 伪标签，不吃 source），存在两个风险：
1. **错误累积**：伪标签噪声被反复当真值固化
2. **source 漂移**：模型脱离 source 真实标签

### 修复

**6.1 `min_dann_epochs`（默认 100）**

```python
can_semi = (
    epoch >= args.min_dann_epochs   # 新增：DANN 至少先训满
    and (train_acc >= args.semi_acc or semi_flg)
    and args.pseudo
)
```

DANN 对抗 + AE 至少先训满 100 epoch 才交棒，域对齐更充分。可调 `--min-dann-epochs`。

**6.2 半监督阶段 source + 伪标签联合训练**

```python
# 原来：只吃伪标签
# 现在：source 真实标签 + target 伪标签联合
combined = ConcatDataset([source_dataset, pseudo_dataset])
semi_loader = DataLoader(combined, ...)
```

防漂移、防错误累积。伪标签为空时退回 DANN 训练本 epoch（不空转）。

## 当前代码架构（最终版）

```
hw11_npu.py
├── 数据变换
│   ├── source_transform: Grayscale → 随机Canny → 翻转/旋转 → ToTensor → ×2 RandomErasing
│   ├── target_transform: Grayscale → Resize → 翻转/旋转 → ToTensor → ×2 RandomErasing（无Canny）
│   └── test_transform:   Grayscale → Resize → ToTensor（无Canny，无增强）
│
├── 模型
│   ├── FeatureExtractor: ResNet18（预训练，首层3×3单通道，去MaxPool，输出512维）
│   ├── LabelPredictor:   Dropout(0.5) → 512→512→512→10
│   ├── DomainClassifier: 512→512→512→512→512→1（带BatchNorm）
│   └── Decoder:          512→256→256→128→64→1 反卷积（denoising AE）
│
├── 训练
│   ├── train_epoch:      DANN（分类+域对抗）+ AE重建 + loss_balance
│   ├── train_cls_epoch:  半监督（source+伪标签联合，类反比加权 + balance）
│   └── 调度:             CosineAnnealingLR(eta_min=1e-6)，4优化器共用
│
├── 伪标签
│   ├── generate_pseudo_labels: margin筛选(top2/top1<0.5 & top1≥0.3) + 类反比加权
│   └── 启动条件: epoch≥100 且 train_acc≥0.85
│
├── 推理
│   └── run_inference → balanced_predict（均衡分配，每类N/10）
│
└── 模式
    ├── --mode all:    DANN训练 + 伪标签 + 推理
    ├── --mode train:  仅训练
    ├── --mode infer:  仅推理
    └── --mode pseudo: 载入旧权重，仅伪标签微调 + 推理
```

## 关键经验教训

### 1. 输入变换一致性是域适应的生死线

阶段 3 的 `0/100000` bug 教训深刻：源域做了 Canny、目标域没做，输入空间不一致 → 特征无意义 → softmax 均匀。**域适应中，源/目标域的输入预处理必须保证特征空间对齐**，否则一切后续都白搭。

### 2. 但"一致"不等于"完全相同"——要看域的本质

阶段 5 修正了阶段 3 的过度修复：target 是手绘涂鸦，本身已是边缘图，再做 Canny 是二次边缘化。**正确做法是 source 做 Canny（让照片像涂鸦），target 保持原始灰度**。判断依据是"域的本质特征"，不是机械求一致。

### 3. 半监督启动时机要保护 DANN 阶段

ResNet18 + 预训练权重收敛快，45 epoch 就到 0.85，若直接切半监督则 DANN 对抗阶段只占 9%，域对齐严重不足。`min_dann_epochs` 保证 DANN 先充分训练，是强 backbone + 半监督的关键保护机制。

### 4. 半监督不能脱离 source

纯伪标签自训练（只吃 target）会导致 source 漂移 + 错误累积。联合训练（source + pseudo）用 source 信号稀释伪标签噪声，对强 backbone 更稳。

### 5. 参考实现要"取其精华"，不必照搬架构

参考作业用 5 层 conv，我们保留 ResNet18（已验证 0.73274），只采纳他的损失设计（balance + AE）、数据增强、伪标签策略。**方法可以迁移，架构不必盲从**——前提是接口兼容（512 维特征都能接 Decoder）。

### 6. 进度条 UX：用户要的是每轮可见，不是总进度

500 epoch 的总进度条 ETA 不准且占满一行；每 epoch 自己的批次条让用户看到当前轮内 batch 进度，更符合"盯单轮"的心智模型。
