## 阶段一：鱼书《深度学习入门》全书（05-13 ~ 05-25）

### 学习路线

```
ch3（感知机/激活函数）
  → ch4（梯度/优化）
    → ch5（层实现：Affine/ReLU/Sigmoid/Softmax）
      → ch6（训练优化：BatchNorm/Dropout/Adam/L2）
        → ch7（CNN NumPy + PyTorch 双版本）
          → ch8（VGG 实战 + Tiny ImageNet-200）
```

### 各章节要点

#### ch3~ch4：基础搭建（05-13 ~ 05-15）

- 实现感知机（AND 门）、三层神经网络前向传播
- 数值梯度（有限差分法）、交叉熵误差、softmax 数值稳定性处理
- 二维梯度场可视化、简单网络梯度下降

#### ch5：神经网络层模块化实现（05-15 ~ 05-16）

从零手写 7 种层，构建完整 MNIST 训练流程：

| 层 | 文件 | 功能 |
|:---|:-----|:-----|
| 乘法层 | `multiLayer.py` | 前向/反向传播 |
| 加法层 | `addLayer.py` | 梯度直通 |
| ReLU | `reluLayer.py` | 非线性激活 |
| Sigmoid | `sigmoidLayer.py` | 二分类激活 |
| SoftmaxWithLoss | `softmaxLayer.py` | 多分类 + 交叉熵 |
| Affine | `affineLayer.py` | 全连接（含 bias） |
| 组合层 | `combineLayer.py` | 层串联编排 |

同期删除旧 `neural_network/` 实验，统一到 `fish-book/` 目录下，建立 `common/` 公共模块。

#### ch6：训练优化技巧（05-18）

从零实现现代训练核心技术，MNIST 准确率 49% → **97%**：

- **BatchNormalizationLayer**：前向标准化 + γ/β 缩放平移 + 移动平均；反向传播沿 `out → x̂ → xc → x` 回溯
- **Adam 优化器**：一阶/二阶矩估计 + 偏差修正，替换手动 SGD
- **L2 正则化（Weight Decay）**：`λ=1e-4`，仅对权重施加惩罚
- **Dropout bug 修复**：推理时 `predict` 未透传 `train_flg`，导致 Dropout 仍在丢弃神经元

#### ch7：卷积神经网络（05-19 ~ 05-21）

**NumPy 版（05-19）**——从零理解底层：

- `Convolution` 层：`im2col` 展开 → 矩阵乘法 → 避免多重循环
- `Pooling` 层：最大池化 + `arg_max` 记录最大值位置用于反向传播
- `SimpleConvNet`：`Conv → ReLU → Pool → Affine → ReLU → Affine → SoftmaxWithLoss`

> 因 NumPy 版极慢（多重循环），决定后续改为 PyTorch。

**PyTorch 版（05-21）**——工程化对比：

- 用 `nn.Module` 实现等价 CNN，与 NumPy 版逐组件对比（卷积、池化、全连接、损失、优化器）
- 重构 `common/` 模块：新增 `__init__.py`、`utils.py`，删除旧 `network.py`

#### ch8：VGG 实战（05-22 ~ 05-24）

- 实现 VGG11/13/16/19，通过配置列表驱动网络构建
- **小卷积核堆叠设计**：两个 3×3 等效 5×5 感受野，参数减少 ~45%
- 通用训练框架：`train.py` + 模型注册中心 + Tiny ImageNet-200 数据加载器
- **多平台训练**（最佳结果 VGG11，Tiny ImageNet-200）：

| 平台 | 最佳准确率 | 训练时长 |
|:-----|:----------:|:--------|
| 昇腾 910B3 | **52.11%** | ~23 min |
| Kaggle T4×2 | 51.33% | ~91 min |

> 超越参考论文（VGG16, 49.4%）约 2.7%，通过增大 weight_decay=0.001 + dropout=0.6 缓解过拟合。

### 鱼书核心收获

1. **从零理解反向传播**：手写所有层的 forward/backward，掌握链式法则的计算图视角
2. **im2col 技巧**：将卷积转为矩阵乘法，是 NumPy 实现高性能 CNN 的关键
3. **训练优化全景**：权重初始化 → BatchNorm → Dropout → Adam → L2，每项都有 NumPy 实现
4. **算力平台实操**：Colab T4、Kaggle T4×2、昇腾 910B3 三端完整训练经验

## 阶段二：刘二大人 PyTorch 教程（05-26 ~ 05-31）

### 学习路线

```
线性回归（lecture-5）
  → 逻辑回归（lecture-6）
    → MLP 多层感知机（lecture-7）
      → MNIST 数据加载（lecture-8）
        → 全连接 MNIST 分类（lecture-9）
          → CNN MNIST 分类（lecture-10）
            → GoogLeNet Inception（lecture-11/12）
              → RNN/GRU 姓名分类 + 情感分析（lecture-13）
```

### 各讲要点

| 讲次 | 主题 | 模型 | 技术要点 |
|:-----|:-----|:-----|:---------|
| 5 | 线性回归 | `Linear(1,1)` + MSELoss + SGD | 从数据生成到可视化完整流程 |
| 6 | 逻辑回归 | `Linear(1,1)` + Sigmoid + BCELoss | 概率输出、决策边界 |
| 7 | MLP 分类 | 三层全连接 + BCEWithLogitsLoss + Adam | 糖尿病二分类，误分类可视化 |
| 8 | 数据加载 | DataLoader | MNIST 标准化数据管道 |
| 9 | 全连接 MNIST | 五层 FC(784→512→256→128→64→10) | SGD+Momentum，观察参数变化 |
| 10 | CNN MNIST | 三层 Conv + MaxPool + FC | 参数共享、局部连接优势 |
| 11-12 | GoogLeNet | InceptionA 多分支 | 1×1 降维、微特征图性能分析 |
| 13 | RNN 实战 | 双向 GRU + Embedding | 姓名国籍分类 + Bi-LSTM 情感分析 |

### 关键学习笔记

- **BCEWithLogitsLoss vs BCELoss**：前者 = sigmoid + BCELoss，数值更稳定
- **全连接 vs 卷积**：FC 参数量大易过拟合，CNN 参数共享 + 局部连接适合图像
- **padding 规则**：奇数卷积核 `padding = kernel_size // 2` 保持尺寸不变
- **情感分析实战（lecture-13-exercise-1）**：Embedding → Bi-LSTM → FC → 5 分类，最高准确率 **65.5%**，产出了架构图 + 训练文档
